# 📝 Smart Notes

A colorful, interactive desktop notes and task management application built around the simplicity of sticky notes.

Smart Notes brings organization to life with vibrant note colors, drag-and-drop functionality, and rewarding task completion animations.

## ✨ Features

- **Colorful Sticky Notes** – Create and organize notes using vibrant colors.
- **Drag & Drop** – Freely arrange notes to build your own workspace.
- **Task Management** – Keep track of tasks and mark them as complete.
- **Rewarding Animations** – Celebrate completed tasks with confetti and stars.
- **System Tray Integration** – Closing the window asks whether to keep Smart Notes running in the tray (so reminders keep firing) or quit. Tick "Remember my choice" to skip the prompt; change it any time from the tray menu under "When I close the window".
- **Automatic Updates** – Receive and install application updates directly through GitHub releases.

## 🚀 Getting Started

### Prerequisites

- [Node.js](https://nodejs.org/)
- npm

### Installation

Clone the repository:

```bash
git clone https://github.com/TheDataDave/smart-notes.git
cd smart-notes
```

Install dependencies:

```bash
npm install
npm --prefix client install
```

Start the development environment:

```bash
npm run dev
```

### Build

Build the React frontend:

```bash
npm run build:client
```

Launch the packaged application locally:

```bash
npm start
```
